# Core Concepts

The data model behind every number in Genezio. Worth twenty minutes early —
most confusion later traces back to one of these.

A **brand** is what buyers ask about. A **topic** is a subject they ask about.
A **scenario** is one realistic way of asking it. Running a scenario against an
answer engine produces a **conversation**, and conversations are where every
metric comes from.

Inside an answer, Genezio detects **citations** (the sources used),
**competitors** (brands named as alternatives), and **perceptions** (claims
made about you).
