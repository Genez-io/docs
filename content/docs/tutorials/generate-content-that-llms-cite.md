# Generate Content That LLMs Cite

End to end: from a gap in the data to a published piece that gets quoted.

---

## 1. Start from a gap that is real

Use [Content Opportunities](../insights/content-opportunities.html): a question
being asked, a competitor present, you absent.

Apply the honest filter — can you credibly be the answer? If the question is
about a capability you do not have, visibility will not help.

## 2. Take the fanouts, not the title

Open the [query fanouts](../analysis/extracting-query-fanouts.html) for the
topic. They are what retrieval actually looked for, and they tell you the
sub-questions the piece must answer and the vocabulary to use.

Group them by intent. One group is one piece.

## 3. Brief it properly

The [brief](../content-hub/briefs.html) is where the thinking goes: the
questions, the audience, the sources. A brief built from fanouts gives the
writer a list of questions instead of a subject.

## 4. Generate, then edit as an editor

[Generate the article](../content-hub/generating-articles.html), then apply one
test to every paragraph: does it answer something on its own, without the
paragraph before it?

If not, it is not quotable, however well it reads. See
[Structuring Content for LLMs](../improving-ai-visibility/structuring-content-for-llms.html).

## 5. Publish so it can be read

Not gated, not only in a PDF or video, on a crawlable URL — and take the
[schema markup](../content-hub/schema-markup.html) with it. See
[Publishing Content](../content-hub/publishing-content.html).

## 6. Measure, patiently

Note the date, keep running the topic, and watch whether the page appears in
[Most Cited Sources](../insights/most-cited-sources.html).

Citation lags publication by weeks. One run is not a verdict. If it is still
absent after several, read what *is* cited for that question and compare
honestly.
