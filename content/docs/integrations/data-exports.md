# Data Exports

Genezio reports can leave the product, for a board pack, a client report or a
warehouse.

---

## PDF

Reports and content analyses can be downloaded as PDF. This is the right format
for a document somebody reads — a monthly client report, a slide appendix, a
record of where things stood.

---

## CSV

Tabular views export to CSV for a spreadsheet or a warehouse. Useful when you
want to combine Genezio numbers with data it does not hold — pipeline, revenue,
campaign spend.

---

## The API, for anything repeated

If an export is something you will do every month, use the
[API](../api/index.html) instead of exporting by hand. It reaches brands,
topics, conversations, citations, visibility, content and the Business
Scorecard, and it returns the same numbers the dashboard shows.

The practical rule: export by hand for a one-off, use the API for a routine.
A monthly manual export is a job somebody will eventually forget to do.

---

## A note on comparing exports

An export is a snapshot of a moving measurement. Two exports a week apart will
differ partly because answer engines vary between runs. When comparing, use the
same topics and the same engines, and read direction rather than small
differences. See [Trend Tracking](../dashboards/trend-tracking.html).
